# 🛒 Blinkit Sales Analysis Dashboard | Power BI

## 📌 Project Overview

This project is an interactive Power BI dashboard built using the Blinkit Grocery Dataset. The dashboard provides insights into sales performance, outlet characteristics, customer ratings, item distribution, and profitability trends across different outlet types, sizes, and locations.

The objective of this project is to demonstrate data visualization, business intelligence, KPI analysis, and dashboard development skills using Power BI.

## 🎯 Business Problem

Blinkit operates multiple grocery outlets across different locations and outlet sizes. Understanding sales patterns, customer ratings, inventory distribution, and outlet performance is essential for making data-driven business decisions.

This dashboard helps answer questions such as:

- Which outlet type generates the highest sales?
- Which outlet location performs best?
- How does fat content impact sales?
- Which item categories contribute the most revenue?
- How do outlet sizes affect overall sales?
- What are the average sales and ratings across outlets?

---

## 🧮 DAX Measures Used

### Total Sales

```DAX
Total Sales = SUM('BlinkIT Grocery Data'[Sales])
```

### Average Sales

```DAX
Average Sales = AVERAGE('BlinkIT Grocery Data'[Sales])
```

### Number of Items

```DAX
No Of Items = COUNT('BlinkIT Grocery Data'[Item Identifier])
```

### Average Rating

```DAX
Avg Rating = AVERAGE('BlinkIT Grocery Data'[Rating])
```

## 💡 Key Insights

- Tier 3 outlets generated the highest sales.
- Regular fat products contributed more sales than low-fat products.
- Medium-sized outlets showed strong overall performance.
- Fruits & Vegetables and Snack Foods were among the top-selling categories.
- Supermarket Type 1 generated the highest revenue among outlet types.
